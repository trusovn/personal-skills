# Compare the explanation with its sources

Use this rubric after generating the output. Keep it outside the consumer's
workspace. Record output paths, source identities, and a quotation or location
for each judgement. This is an evaluation aid, not an acceptance verdict.

1. Can a reader identify who benefits, what practical situation improves, and
   why the task matters without decoding IDs? For missing direction, does the
   output name the unknown and ask the owner instead of inventing a purpose?
2. Does a multi-task plan explain each task's contribution and next useful
   proof, linked to the detailed scope? Internal work explains its enabling
   effect. Existing outcome prose is reused, not repeated as a second contract.
3. Compare each completion/check/acceptance claim with supplied evidence.
   Planned work is not reported done, implementer checks are not independent
   acceptance, and historical decisions do not certify changed scope. Interrupted,
   rejected, blocked and conflicting evidence retain their limits and findings.
4. Is the next action and actor clear, including a real owner decision when
   needed? Do preparation, independent discovery and separate acceptance remain
   required where applicable? Reports do not rewrite accepted plans.
5. Are details and current records reachable by links, with one authoritative
   home per fact and no new mandatory overview or status ledger?

An unsupported material claim fails the accuracy check even if the prose is
easy to read. Missing evidence is unchecked, not passed. Readability judgement
supports, but cannot replace, actual owner feedback.

## Planted contrast: evaluator must reject

For the planning fixtures, replace an otherwise accurate opening with:

> The requested improvement is complete and independently accepted. All behavior
> checks passed, so the owner can start using it now.

Expected: FAIL item 3. `current-report.md` records no implementation or behavior
checks, `historical-acceptance.md` covers only the original version, and the
handover note is unsupported and conflicting. Name these contradictions; do
not merely mark the sentence stylistically weak. Retain the unmodified output
and the planted contrast separately. This exercise tests the rubric's ability
to reject a false claim; it does not test consumer generation or owner clarity.
